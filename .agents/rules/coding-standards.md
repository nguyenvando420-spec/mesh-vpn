## 2. Format, Đặt tên & Tổ chức Mã theo OS
- **Format (`rustfmt.toml`)**: 4 spaces `.rs` (2 spaces `.toml/.json/.yml/.sh`), ≤ 100 cột, LF (`.ps1/.bat/.cmd` = CRLF), **UTF-8 KHÔNG BOM**. Code/comment/log/lỗi/commit bằng **tiếng Anh**.
- **Thứ tự `use`**: (1) `std`/`core`/`alloc` → (2) external crates → (3) `mesh_*`/`crate`/`super`/`self`. Cấm `use ...::*;` ngoài `mod tests`.
- **Đặt tên**: Crate `kebab-case`; module/file/fn/var `snake_case` (cấm `util.rs`/`common.rs`/`helpers.rs`, getter không `get_`); struct/enum/trait `PascalCase`; const/static `SCREAMING_SNAKE_CASE`; bảng `redb` & JSON/TOML `snake_case`; thời điểm `*_at_ms` (`u64` UTC); env `MESH_*`; CLI `mesh <noun> <verb> --kebab-flag`.
- **Mã theo OS (`cfg(target_os)`)**: Logic lõi OS-neutral. Phần chạm OS định nghĩa bằng Trait trong `mesh-net` + Fake RAM (`cargo test` xanh không cần root/Admin). Tách `<name>_{linux,macos,windows}.rs` (`#[cfg(target_os = "...")]`). Cấm `std::env::consts::OS` rẽ nhánh nghiệp vụ.

## 3. An toàn Bộ nhớ, Kiểu & Xử lý Lỗi (Clippy `-D warnings`)
- **Cô lập `unsafe` (tránh `E0453`)**: `[workspace.lints.rust] unsafe_code = "forbid"` cho mọi crate (`[lints] workspace = true`), kể cả `mesh-client` và `tools/uniffi-bindgen`. Hai ngoại lệ duy nhất không đặt `[lints] workspace = true` để tránh `E0453`:
  - `crates/mesh-sys/Cargo.toml`: `[lints.rust]` (`unsafe_code = "allow"`, `unsafe_op_in_unsafe_fn = "deny"`) + `[lints.clippy]` (`undocumented_unsafe_blocks = "deny"`, `unwrap_used = "deny"`, `expect_used = "deny"`, `panic = "deny"`, `indexing_slicing = "deny"`) kèm `// SAFETY:`.
  - `crates/mesh-mobile-ffi/Cargo.toml`: `[lints.rust]` (`unsafe_code = "allow"`, `unsafe_op_in_unsafe_fn = "deny"`, cho phép macro `uniffi` sinh `#[unsafe(no_mangle)]`) + `[lints.clippy]` đầy đủ như workspace — **cấm 0 dòng `unsafe` viết tay** trong `crates/mesh-mobile-ffi/src/*.rs` (kiểm bởi `scripts/check.{ps1,sh}`).
- **Cấm panic**: Cấm `.unwrap()`, `.expect()`, `panic!()`, `todo!()`, `unimplemented!()`, `unreachable!()`, `dbg!()`, `println!()`/`eprintln!()` (trừ CLI `crates/mesh`), `slice[i]` (`.get(...)`/`split_at_checked`), `let _ = f()`.
- **Kiểu miền (`mesh-core`)**: Parse tại biên thành newtype (`NodeId`, `NodeName` RFC 1123 1..=63 `[a-z0-9-]`, `OverlayIp`, `Port`, `PublicKey([u8; 32])`, `SpkiPin`). Frame ≤ 2048 B. Cấm cứng cổng `443`/`3478` ngoài `mesh_core::defaults` (`GNFR-11`).
- **Lỗi (`thiserror` + `AppError`)**: Khi `ErrorKind::Unauthenticated`, luôn trả **duy nhất** `"authentication failed"` (`SEC-05`). Xử lý lỗi 1 lần (return `?` HOẶC log ở biên).

## 4. Async / Tokio Concurrency & Vòng đời (`Graceful Shutdown ≤ 5 s`)
- Task nền nhận `CancellationToken`, chạy trong `TaskTracker`/`JoinSet` (cấm `tokio::spawn` mồ côi), thoát **≤ 5 s** khi dừng (dọn theo `ResourceLedger`). Cấm giữ `std::sync::MutexGuard` qua `.await` (`await_holding_lock = "deny"`). Cấm `std::thread::sleep` trong async.
- **Blind Relay (`US-025 AC6`)**: Cấm `unbounded_channel`. Mỗi đích dùng `mpsc::channel(256)` + **`try_send()`** (đầy: drop-tail + tăng metric, cấm `.send().await` gây HoL blocking).
- I/O mạng có `tokio::time::timeout` (connect ≤ 10 s, heartbeat ≤ 60 s). Reconnect `ExponentialBackoff` + full jitter; lỗi TLS/Captive Portal/clock skew/pin mismatch retry trần 5m (chỉ dừng khi nhận `node_revoked`/`node_key_expired` qua TLS hợp lệ — `US-034`).

## 5. Bảo mật Khóa, Kênh Admin & An toàn Máy thật (`SEC-01`, `SEC-04`, `SEC-14`, `G4`)
- **Bí mật trong RAM (`SEC-01`)**: Private key & pre-auth key thô chỉ trong `mesh_crypto::Secret<T>` (`ZeroizeOnDrop`; `Debug`/`Display`/`Serialize` → `"[REDACTED]"`). `.expose_secret()` chỉ gọi trong `mesh-crypto`, `mesh-datapath`, `mesh-net` (keystore) và `mesh` (in key 1 lần). Không nhận key qua argv mặc định. Test `test_no_secrets_in_outputs` phải xanh.
- **TLS & SPKI Pin (`SEC-04`)**: IP + SPKI Pin (`sha256:<hex>`) mặc định hạng nhất; `SpkiPinVerifier` dùng `x509-cert` lấy `tbs_certificate.subject_public_key_info` DER + kiểm hạn `NotBefore`/`NotAfter` (`ErrorKind::ClockSkew`), so sánh SHA-256 `ConstantTimeEq`, fail-closed khi thiếu pin, **cấm TOFU**, không cờ bypass.
- **IPC (`SEC-14`)**: Server Linux (`/run/mesh-server` `0750 mesh:mesh-admin`): `/run/mesh-server/admin.sock` (`0660 mesh:mesh-admin`, `SO_PEERCRED` + `getgrouplist`). Client `meshd` (`/var/run/meshd` `0755`) tách **2 kênh**: (1) Admin `/var/run/meshd/meshd-admin.sock` (`0660 root:admin` macOS `xucred.cr_groups` `gid==80` + fallback `getgrouplist`; `0660 root:mesh-admin` / `0600 root:root` Linux) / `\\.\pipe\mesh-agent-admin` SDDL (`SY`+`BA`) và (2) Read-only (`status`/`peers`/`ping`/`netcheck`, 0 secrets, ≤ 4 KiB) `/var/run/meshd/meshd-ro.sock` (`0666`) / `\\.\pipe\mesh-agent-ro`. **Cấm** Admin API trên TCP. `/healthz`, `/readyz`, `/metrics` ở listener riêng chỉ-đọc.
- **Bảo vệ Máy thật (`G4`)**:
  - **Sổ cái (`ResourceLedger`)**: Ghi (`utunN`, adapter GUID, route, `ip rule`/`table 51820`, hosts, `pf`, firewall) vào đĩa `0600` (`/var/db/mesh/ledger.json`, `/var/lib/meshd/ledger.json`, `C:\ProgramData\Mesh\ledger.json`) **trước khi tạo**; chỉ dọn theo sổ cái (cấm xóa `utun*`).
  - **Chống Routing Loop (`REL-09`)**: Ràng socket ngoại biên vào NIC vật lý (`IP_BOUND_IF` macOS, `IP_UNICAST_IF` Windows, Linux `SO_MARK = 0x5d56` + `table 51820` + `ip rule` `priority 51820 not fwmark 0x5d56 table 51820` & `priority 51810 table main suppress_prefixlength 0`); chỉ route dải overlay.
  - **Khối `hosts` (`PLAT-04`)**: Chỉ sửa `# BEGIN mesh … # END mesh`; giữ symlink `/etc/hosts` macOS và ACL đọc Windows; chặn `localhost, broadcasthost, wpad, isatap, local` và hostname/IP public VPS.
  - **Windows, macOS & `sysexec`**: Kiểm SHA-256 `wintun.dll` trước khi nạp (`LOAD_LIBRARY_SEARCH_APPLICATION_DIR`); macOS kiểm binary/plist thuộc `root` (`mode & 0o022 == 0`), cấm `spctl --master-disable`. Lệnh ngoài chỉ qua `mesh_net::sysexec` với đường dẫn tuyệt đối (`/sbin/{ifconfig,route,pfctl}`, `/usr/bin/{dscacheutil,killall,systemctl}`, `/usr/libexec/ApplicationFirewall/socketfilterfw`, `/bin/launchctl`, `/usr/sbin/{ip,nft,iptables,ufw}`, `/sbin/ip`, Windows `GetSystemDirectoryW` + `System32\{netsh,ipconfig,route}.exe`, cấm shell).
- **Log (`OPS-01`)**: `tracing` JSON; bắt buộc `ts` (UTC), `level`, `component`, `event`.
