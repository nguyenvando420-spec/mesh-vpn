## 4. ⚖️ Đánh Đổi Chiến Lược Khách Quan (`Strategic Trade-offs` — Trình Người Dùng Tại Unified UI Gate 2)

Bộ thiết kế kỹ thuật và kế hoạch Sprint `v0.4.0` đặt trên **3 đánh đổi chiến lược rõ ràng** cần được trình bày minh bạch để Người dùng phê duyệt tại **Unified UI Gate 2**:

1. **Vẽ tùy biến Win32 GDI + Memory DC Double-Buffering + `WS_CLIPCHILDREN` (`ADR-027`) vs Nhúng Framework Đồ họa Ngoài (`egui` / `iced` / `WebView2`)**:
   - **Lợi ích đạt được**: Giữ nguyên tuyệt đối `0` crate mới ngoài `deny.toml`, `0` dòng `unsafe` trong `crates/mesh-gui`, tệp thực thi `MeshVPN.exe <= 6 MiB` (`2.43 MiB` thực tế — còn `60%` dư địa) và mức RAM chạy ngầm khay hệ thống `<= 15 MiB`.
   - **Chi phí / Đánh đổi chấp nhận**: Các nút bấm CTA, thanh Tab Bar 3 mục, Status Pill và thẻ bo góc ở chế độ Dark Mode phải vẽ qua `BS_OWNERDRAW` (`WM_DRAWITEM`) và bộ đệm `OwnedMemDc` + `OwnedGdiObj` thay vì dựa vào `WM_CTLCOLORBTN` mặc định của `USER32`. Rủi ro rò rỉ tài nguyên đồ họa được khóa bằng cổng kiểm thử tự động `GetGuiResources(GR_GDIOBJECTS) delta == 0` sau `100` chu kỳ vẽ/đổi theme (`US-136`).

2. **Tra cứu Gói Ngôn ngữ `.lproj` Tường minh + `ContextWrapper(activity)` + Bảng Tĩnh RAM (`ADR-029`) vs Đổi Ngôn ngữ Phải Khởi động Lại Tiến trình**:
   - **Lợi ích đạt được**: Đáp ứng trọn vẹn `DEC-UI-04` chuyển đổi tức thì `System / Tiếng Việt / English` ngay trong màn Settings mà **không khởi động lại daemon hay ngắt kết nối WireGuard**, tương thích đồng thời với `iOS 15.0+` (nơi chưa có API `String(localized:locale:)`), `FragmentActivity` trên Android (`0` `androidx.appcompat`, bảo toàn `BiometricPrompt`), và kiểm thử đơn vị song song dưới Swift 6 `Sendable`.
