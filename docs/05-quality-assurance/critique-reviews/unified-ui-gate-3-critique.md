## 3. ⚖️ Đánh Đổi Chiến Lược Kiến Trúc (Strategic Trade-offs)

1. **Từ điển Biên dịch Tĩnh `213` Khóa (`i18n.rs`, SwiftPM `.strings`, `Localizable.xcstrings`, `strings.xml`) + Helper Nội Tuyến Nhẹ so với Gói Ngôn ngữ Động Tải Ngoài (`ADR-029`)**:
   - *Lợi ích đạt được*: Triệt tiêu hoàn toàn bề mặt tấn công giả mạo tệp dịch trên đĩa, `0` lỗi thiếu tệp lúc chạy, chuyển đổi ngôn ngữ tức thì `< 16 ms` (`AtomicU8` / `@Published` / `ContextWrapper`) cả trước và sau khi enroll mà không cần khởi động lại daemon đặc quyền hay ngắt đường hầm WireGuard.
   - *Chi phí chấp nhận*: Mọi chỉnh sửa câu chữ giao diện đều đi theo chu kỳ phát hành nhị phân tiếp theo thay vì cập nhật nóng OTA.
2. **Lưu Tùy chọn Giao diện/Ngôn ngữ ở Không gian Người dùng (`ui-prefs.json` / `UserDefaults` / `SharedPreferences`) Tách Rời `bootstrap.toml` của Daemon (`ADR-031`)**:
   - *Lợi ích đạt được*: Đổi Theme/Language với `0` hộp thoại nâng quyền (`UAC` / `Polkit` / `osascript` / `BiometricPrompt`), giữ `ui-prefs.json` hoàn toàn vô hại (`SEC-01`, chỉ chứa 2 trường `theme` & `locale`, `0` khóa bí mật), tự động hồi phục về `System` khi tệp hỏng.
   - *Chi phí chấp nhận*: Trên máy trạm Windows/macOS nhiều tài khoản người dùng OS, mỗi tài khoản lưu tùy chọn giao diện/ngôn ngữ riêng biệt thay vì dùng chung toàn máy qua daemon.
3. **Win32 GDI Thuần + `UxTheme`/`DwmSetWindowAttribute` (`2.57 MiB` `MeshVPN.exe`) so với WebView2 / WinUI 3 (`ADR-027`, `ADR-030`)**:
   - *Lợi ích đạt được*: Giữ trọn vẹn tệp thực thi đơn lẻ siêu gọn **`2,699,264 bytes` (`2.57 MiB <= 6.00 MiB`)**, RAM ~4–10 MB, `0` phụ thuộc runtime ngoài, `0` rò rỉ GDI (`delta == 0` sau 100 chu kỳ), điều hướng bàn phím `Tab`/`←`/`→` mượt mà (`WS_EX_CONTROLPARENT` + `GetNextDlgTabItem`) và tương thích đầy đủ High-Contrast `GetSysColor` (*Desert* & *Aquatic*).
   - *Chi phí chấp nhận*: Bố cục hình học (`ControlRect`) và owner-draw được tính toán tường minh theo DPI trong Rust thay vì hệ thống layout khai báo CSS/XAML, đổi lại tốc độ khởi động tức thì và bề mặt tấn công tối thiểu.
4. **Phân tầng Trung thực Kiểm định 3 Mức (`VERIFIED_ON_WINDOWS_HOST` / `PENDING_CI_RUNNER` / `hardware_signoff_required`)**:
   - *Lợi ích đạt được*: Đảm bảo tính minh bạch tuyệt đối trên máy chủ phát triển Windows không có Xcode/macOS hay Android SDK/Emulator, đồng thời khóa chặt các cổng kiểm tra bắt buộc trên GitHub Actions (`ci.yml`, `mobile-android.yml`, `mobile-ios.yml`, `release.yml`) và sổ cái nghiệm thu phần cứng vật lý (`docs/06-operations/unified-ui-hardware-acceptance-protocol.md`) trước khi cắt tag phát hành `v0.4.0`.
