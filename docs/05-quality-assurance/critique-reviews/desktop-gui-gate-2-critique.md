## 2. Tóm Tắt Đánh Đổi Chiến Lược Trình Người Dùng Tại Gate 2 (`Strategic Trade-offs Summary`)

1. **Thuần Native OS (`Win32 windows-sys 0.59` + `macOS Swift 6 AppKit/SwiftUI`) vs WebView2/Tauri/Electron (`OQ-DGUI-02`, `ADR-020`, `ADR-025`)**:
   - *Lợi ích đạt được*: **`0` thêm crate bên thứ ba vào `Cargo.lock`**, **`0` thay đổi `deny.toml`**, binary `MeshVPN.exe` siêu gọn **`<= 4–6 MiB`**, RAM rảnh tại Tray **`<= 15 MiB`** (Windows) / **`<= 35 MiB`** (macOS) thay vì `100–250 MiB` của WebView2/Chromium, và chạy ngay trên máy Windows 10 sạch không cài WebView2 Runtime cũng như biên dịch sạch với MinGW `x86_64-pc-windows-gnu`.
   - *Chi phí chấp nhận*: Tự quản lý bố cục Win32 Common Controls + DPI `PerMonitorV2` qua lớp bọc an toàn RAII trong `crates/mesh-sys/src/gui_windows.rs` (`unsafe` bị cấm tuyệt đối ở `crates/mesh-gui`).
2. **Phân tách Đặc quyền Tối thiểu (`asInvoker` + Ephemeral Named Pipe `MGH1` trên Windows · Non-Sandboxed `gid = 80` + `osascript` cố định trên macOS) (`ADR-021`, `ADR-023`, `ADR-025`)**:
   - *Lợi ích đạt được*: Giữ nguyên bất biến bảo mật `ADMIN_PIPE_SDDL` (`SY+BA`) và `/var/run/meshd/meshd-admin.sock` (`0660 root:admin`), **`0` Admin TCP listener**, **`0` lộ `mpk_*` qua `argv`/PEB/WMI hay file tạm trên đĩa**. Trên macOS, quản trị viên máy (`gid = 80`) bật/tắt VPN và xuất bugreport với **`0` hộp thoại mật khẩu**; trên Windows, hỗ trợ đầy đủ cả tài khoản Admin Split-Token lẫn Standard User Over-The-Shoulder (OTS) UAC nhờ bắt tay `0x00 WorkerHello` + `SecurityIdentification`, đồng thời triệt tiêu 100% lỗ hổng Arbitrary File Overwrite EoP nhờ **Atomic Temp-Sibling Sink Write**.
   - *Chi phí chấp nhận*: Trên Windows, vì `ADMIN_PIPE_SDDL` khóa chặt `SY+BA` (không nới cho `Authenticated Users` để chống malware Medium Integrity chiếm quyền VPN), các thao tác thay đổi trạng thái (`Connect`/`Disconnect`/`Update`/`Export Bugreport`) sẽ hiện hộp thoại xác nhận UAC chuẩn của hệ điều hành, trong khi mọi thao tác theo dõi (`Status`, `Peers`, `Ping`, `Netcheck`, `Copy IP`) hoàn toàn **`0` UAC**.
3. **Đóng gói `$0` Ad-hoc Hiện tại vs Ký số Thương mại Tương lai (`ADR-026`, `US-114`, `US-117`)**:
   - *Lợi ích đạt được*: Toàn bộ pipeline CI/Release chạy xanh `100%` với chi phí **`$0`**, bảo toàn khớp SHA-256 tuyệt đối giữa `Contents/Resources/SHA256SUMS` và binary `meshd`/`mesh` sau khi ký outer `Mesh VPN.app` (không `--deep`), đồng thời sẵn sàng kích hoạt tự động Authenticode / Apple Developer ID + Notarization ngay khi cấu hình chứng chỉ trả phí (`paid_cert_required`).
