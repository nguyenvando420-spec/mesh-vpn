## 1. Pre-Flight Quality & SLO Suite Commands

Run these commands cleanly before completing the 20-item sign-off table:

```bash
# Linux / macOS workspace gate (fmt, clippy -D warnings, tests, cargo-deny):
sh scripts/check.sh

# Linux SLO + verification suite:
bash scripts/run-slo-suite.sh --output-dir docs/05-quality-assurance

# Linux NAT / chaos suite (Docker required):
bash lab/scenarios/run-all-chaos.sh --report-json docs/05-quality-assurance/chaos-report.json

# macOS host privilege/launchd/utun verification (on physical Mac):
sudo bash lab/macos/verify-macos-host.sh
```

```powershell
# Windows workspace gate & SLO verification suite:
powershell -ExecutionPolicy Bypass -File scripts/check.ps1
powershell -ExecutionPolicy Bypass -File scripts/run-slo-suite.ps1 -OutputDir docs\05-quality-assurance
```
